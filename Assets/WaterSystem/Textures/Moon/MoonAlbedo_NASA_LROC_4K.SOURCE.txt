Projection: global cylindrical/equirectangular longitude-latitude map, centered
on lunar longitude 0 degrees. North is at the top; latitude 0 is the middle row.
Longitude 0 at UV (0.5, 0.5) shows the near side viewed from Earth. The left and
right edges meet on the far side. This is a surface color/albedo map, not a
photograph of a pre-lit moon disc, so it can be mapped onto a shader sphere.

The NASA color product is gamma-corrected/white-balanced for human appearance,
not calibrated scientific reflectance. The chosen 2019 map is sRGB-like LDR,
not linear EXR or HDR radiance. Import with sRGB on for Unity linear rendering.
The full-color source covers approximately 70 N to 70 S; polar areas were filled
using a lower-resolution monochrome albedo map, which is visible in the texture.

Unity import: Default 2D; maximum 4096; sRGB on; Repeat U and Clamp V;
trilinear filtering, mipmaps, no alpha; high-quality compression. Local QA PNG
is a display preview only and is not part of the game asset.
