# 天空与体积云

`AtmosphereRenderer` 的 `Clouds` 使用三维形状噪声、细节侵蚀和球壳内的光线步进，并不是只在天空盒上绘制的二维云图。默认云层下界为海拔 1500 m，上界为 4100 m；实际有云的高度还由云类型和局部天气决定。

## 晴天白云参数

`CloudSettings` 的新建默认值和 `DeepOceanDemo` 已采用以下晴天积云设置：

| 参数 | 数值 | 作用 |
| --- | --- | --- |
| Bottom Altitude / Thickness | 1500 / 2600 m | 云层允许出现的高度范围 |
| Coverage | 0.5 | 保留云团间的蓝天 |
| Cloud Type / Type Variation | 0.85 / 0.3 | 以较高的积云为主，避免多数云退化为低矮层云 |
| Precipitation | 0.05 | 减少雨云底部的额外压暗 |
| Detail Strength | 0.3 | 保留主体，适度侵蚀云边 |
| Extinction | 0.012 /m | 降低旧设置中过强的光学厚度 |
| Albedo | 0.99 | 高散射、低吸收的水滴 |
| Ambient Strength | 1.2 | 保留天空和地面反照提供的补光 |
| Multi Scattering Attenuation / Contribution / Phase Decay | 0.35 / 0.7 / 0.5 | 让太阳光经过多次散射后进入云体内部 |

其他已经保存的场景会保留自己的序列化参数，不会因为 C# 字段默认值变化自动覆盖。在 `AtmosphereRenderer` 组件右上角的菜单中选择 **Apply Fair Weather Clouds**，可以只应用晴天云形和照明参数，同时保留云层高度、风、采样质量、阴影和反射配置，无需重载场景。

如果编辑器已打开 `DeepOceanDemo`，也可以重新打开场景来载入磁盘上的新参数；有未保存编辑时，优先使用组件菜单，避免因重载丢失其他调参。

云的亮度仍来自太阳、天空和月光，而不是固定输出白色。不要只提高整个大气的 `Exposure` 来修复黑云，否则天空和太阳也会一起过曝。阴天可以提高覆盖率、消光和降水量，或降低多次散射贡献，但不必关闭环境补光。

## 渲染修正

- 云照明使用独立的无云天空环境积分，不再把“已被云遮暗的环境”反过来用作云自己的入射光；场景表面仍使用包含云的环境照明。
- 多次散射由三阶扩展为五阶，并在各阶累积反照率衰减；保留太阳方向、阴影、云底和云顶的明暗差异。
- 高度轮廓在覆盖率筛选和细节侵蚀后作用于密度，避免低覆盖率把云的垂直轮廓过早裁成薄片。
- 风切变的最大水平偏移受云层厚度约束，不再随着累计风位移无限增加，防止运行较长时间后积云被拉成扁平长条；云团平移和细节漂移仍会继续。
- 步长受剩余距离和剩余步数约束。除非云已经接近不透明而提前结束，步进会走完整个可见云层区间；最后一个采样区间也不会越过云层出口。
- 光线步进与合成共用云层求交，处理云下、云中、云上及恰好位于边界的情况，防止向下看时取到地球另一侧的云层。球面求交使用稳定的半径平方差，减少边界处的浮点抵消误差。
- 物理海面和风格化海面在完成自身着色后，合成位于相机与海面之间的体积云。云层不再被后绘制的海面覆盖，云后的海面透过云的剩余透射率显示。
- 反射用的云全景图覆盖上下两个半球，正上方和正下方也有有效的纹理坐标；地面以下不应出现云的方向由同一球壳求交自然排除。
- 大气查找表和云噪声等计算着色器输入按 kernel 显式绑定，避免依赖仅对普通材质设置的全局纹理，以及热重载后出现 `Property ... is not set`。

云仍在不透明物体之后、普通透明物体之前合成。项目的两种海面有专门的前景云合成；其他自行添加、会覆盖背景的透明材质也需要相同处理。对穿入云层的不透明几何体，目前仍按云层入口做遮挡判断，不是逐采样的场景深度裁剪。

## 建议检查的视角

1. 海拔约 20 m 仰视：云的主体呈白色，云底有柔和阴影，云边保留细节。
2. 海拔约 2700 m 平视：可见云侧面的纵向轮廓；进入云团时，能见度随密度变化。
3. 海拔约 6500 m 斜俯视和垂直俯视：可见海面前方的云顶，开启/关闭云层有明显差异。
4. 分别检查物理和风格化海面，避免只修复一种材质。
5. 检查日落和夜间：云仍随太阳衰减及月光变化，不应变成不受时间影响的自发光白色。

低分辨率步进配合时间重投影可能在快速移动时暂时变软。需要更精细的近距离云边时，可将 `Downsample` 从 2 改为 1，或将 `Max Steps` 从 128 提高到 192–256；这会增加 GPU 开销，不建议靠无限提高消光来弥补采样不足。
